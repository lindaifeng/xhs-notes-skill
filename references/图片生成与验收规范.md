# 图片生成与验收规范

## 生图前

1. 从 `内容文档.md` 锁定本页全部核心可见文字，不让生图模型自行改写事实、数字或结论。
2. 明确本页知识关系、文字层级、图解功能、人物是否必要和最终画布。
3. 先锁定本套统一背景色：默认纯白色，可按选题内容调整；在每页提示词中明确该颜色，并确保封面与正文全部一致。
4. 传入人物身份主参考；有封面或正文结构参考时，选择最匹配的一张。参考图只引导风格和结构，不复制内容。
5. 正文页由模型确认知识关系完整、动作可执行、原因与边界足够，并且文字量适合画布；信息空泛或过密时先改内容，不用字符计数决定是否生图。
6. 数字型选题在生图前核对：标题数字、内容文档中的数字承诺映射、各页连续编号和发布正文中的动作数量一致；存在重复项或缺项时先改文案。
7. 为每张正文页明确一个图解任务（流程、分流、对照、空间、轮换或判断）。相邻页图解任务相同且没有新的知识关系时，先重设页面结构。
8. 为每页明确人物预算：完整人物出现次数、允许出现的条目、最大画面占比，以及其余条目是否仅使用物品或手部。人物不是必要信息时默认不出现，禁止为了填空在多个条目机械重复同一人物。
9. 把人物 IP 的必选特征与禁用特征写入每页提示词；“参考人物图”不能代替文字约束。具体特征来自使用者私有人物规范，不预设人物外貌或标志配饰。

## 生图方式

交由 Codex 自身生图能力生成，或采用其他可用生图模型；第三方服务由使用者配置自己的 Key。使用当前实际可用且支持所需参考图的工具，不指定模型、不依赖其他 Skill。

目标为 1080x1440 PNG。模型返回其他尺寸时，用可用图像处理能力保持比例转换，不裁断文字、不拉伸画面；随后重新检查。无法达到成品要求时说明限制并停止，不绕过验收。

## 生成方式

- 直接生成可发布的完整图文卡片，不走独立素材后期叠字。
- 必须用生图工具生成正式原图；不得用网页截图、HTML/CSS、程序排版、画布绘制或其他非生图方式冒充 `card-x.png`。
- 原图按顺序命名 `card-1.png`、`card-2.png`……。
- 每生成一页就立即查看原图并验收；失败时重写该页完整提示词后重做，同一问题每页最多返工 3 次，持续失败时停止并报告。
- 用户通过整套生图确认后，连续完成剩余全部页面。单张生成成功不是任务完成条件，不得据此停止或重复向用户索取同一视觉方向的确认。
- 封面提示词明确“本套已锁定背景色、不添加额外背景内容”；仅当模型判断选题需要场景线索时，才加入克制的背景内容，并确保其不遮挡标题、不改变本套锁定背景色。

## 模型视觉验收

逐页检查：

- 标题、编号和中文核心文字是否与 `内容文档.md` 逐项一致，完整、清晰、连续，无漏字、错序、重复、错别字、乱码和擅自改写。
- 是否为 `1080x1440`，元素无裁断，无外加白边或海报套白底。
- 是否与本套已锁定的背景色完全一致；背景色取自使用者视觉设定与本篇方案，未明确变更时不得出现其他底色。
- 信息层级是否先读标题，再读核心判断和细节。
- 封面是否在保持账号视觉与人物 IP 的同时，让用户看懂具体场景、主要收益和内容类型；清单、流程与决策题应呈现克制但足够的内容证据，而不是只靠大人物、大标题和氛围留白。
- 人物面积是否服务于信息层级，没有挤压标题、步骤、图解和内容预告。人物占比由模型结合题材判断，不写死固定比例。
- 封面、正文第一屏和标题是否兑现同一承诺；若封面扩大了好奇但没有筛选到真正需要内容的用户，重做封面表达。
- 正文是否以知识为主，图案没有压过文字。
- 人物符合使用者 IP 的必选与禁用特征；身份、外形、年龄感、出现次数和画面占比均符合本页提示词，动作服务于内容。任何一项不符即判为不通过。
- 相邻页视觉有变化但整套风格一致。
- 是否误放模板名称、设计说明、占位符或提示词文字。
- 正文标题是否仍是中等章节标题，而非挤占正文的大封面式标题。
- 正文页顶部章节标题是否未加 `①②③`、页码、系列序号；序号只能出现在标题下方的正文内容项、步骤、清单或图解节点。标题带序号时直接重做。
- 图解是否解释了文字中的顺序、位置、对照、分流、时间或判断；如果只是在重复摆放主题物件，判为不通过。
- 数字型选题是否能从封面、总览页到展开页连续追踪每个编号，且没有 A/B/C/D 等无必要的第二套编号。
- 成图中的短标签是否只复述内容文档已有关系；新增的事实、时长、条件、动作或医疗表述必须退回内容文档核对后再生成。
- 连续浏览相邻正文页时，是否出现“同一排版骨架只换标题和物件”的疲劳感；出现时至少重做其中一页的知识结构。

以下任一情况属于直接否决，不得通过“整体看起来不错”放行：

- 文案、标题或编号与内容文档不一致；
- 人物 IP 必选特征错误，或人物出现次数超过提示词约束；
- 正文被遮挡、截断或阅读顺序混乱；
- 出现未经内容文档允许的文字、水印、品牌、占位符或提示词；
- 插图与对应条目无关，或只做装饰而没有解释知识关系；
- 原图尺寸不是 `1080x1440`，或最终页数、页码集合不匹配。

事实、文字正确性、视觉和干货密度由模型逐页判断。

不得新增 OCR 分数、视觉打分、语义相似度、信息密度阈值或其他程序化强验收。程序可以帮助读取尺寸、文件和数据，但是否通过仍由模型逐页判断。

## 整套文件检查

按内容文档核对实际文件数量、连续页码、命名与每张 PNG 的 1080x1440 尺寸。通过 Agent 可用的文件信息工具读取，不要求随包脚本，不凭现有最大页码猜测预期总页数。

所有页面都通过文字、编号、人物 IP、知识图解和画布检查后，直接交付整套生成图片，无需截图。工具返回图片只代表该页生成，不代表整套已验收完成。
