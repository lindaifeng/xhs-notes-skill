# 人物 IP 使用规范

读取使用者提供并确认的人物设定与身份参考图。没有现成 IP 时，可按 `assets/模板/人物IP模板.md` 协助起草，确认后生成主参考图并请用户确认；通过后再开始正式卡片。不借用其他账号形象，不把公共模板当成默认人物。

- 身份参考图锁定同一人物，结合用户定义的必选与禁用特征。提示词写清身份约束，不用泛化描述替代图像参考。
- 主参考图不锁定默认表情、视线、姿态、背景、文字或版式。每篇封面为主题选择具体情绪、视线和动作，不机械复用参考姿势。
- 人物用于演示动作、位置、沟通或步骤，正文以知识为主，不为了填空重复人物。没有必要人物的页面可不出现。
- 发型、服装、配饰、年龄感与风格以用户确认的资料为准。逐页核对身份、必选/禁用特征、出现次数和面积预算，错误即返工。
- 生图工具需要能接收所需身份参考图。不可用时先说明缺口，不默默降级或声称身份一致。
- 人物资料与参考图留在用户工作目录，不写回公共规范。
