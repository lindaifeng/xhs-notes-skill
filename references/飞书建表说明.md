# 使用者自建飞书多维表格

在自己的工作区创建 Base 和内容主表，完成用户身份授权。用户向 Agent 指定自己的 Base、内容表与视图；这些标识用于定位资源，访问权限仍由自己的授权控制。不要使用别人的表格标识。

## 内容主表

| 字段 | 类型 | 用途 |
|---|---|---|
| 选题/标题 | 文本 | 与内容文档 H1 完全一致 |
| 看板阶段 | 单选 | 本周候选、创作中、待确认、已发布、暂停；空值表示选题池 |
| 最终图片 | 附件 | 完整有序 card-*.png |
| 发布正文 | 文本 | 可直接发布的正文 |
| 文字质检、视觉质检、文件质检 | 复选框 | 验收通过后更新 |
| 栏目 | 单选 | 按自己的账号栏目创建 |
| 核心结论、选题角度、推荐理由、备注 | 文本 | 选题依据与暂停理由 |
| 优先级 | 单选 | 高、中、低 |
| 计划发布日期、实际发布日期 | 日期 | 排期与复盘，可选 |
| 发布链接 | 文本 | 发布后填写，可选 |

实际字段名按用户表格确定。缺少交付必需字段时先建字段，不默默写入错误字段。无需创建用于上传完整内容文档的字段。

## 视图

- 选题池：表格，过滤看板阶段为空。
- 内容看板：看板，按看板阶段分组，可用最终图片作为封面。
- 已发布归档：表格，过滤看板阶段为已发布。

只有实际操作需要定位视图时再让用户提供对应标识。

## 可选复盘表

基础字段：复盘日期（日期）、复盘状态（单选：已完成/待补数据/观察中）、一句话结论、核心问题、内容方向建议、下阶段行动、数据口径与限制（文本）。按需要增加周期起止日期和曝光、观看、互动、涨粉等数字指标。只读取自己的数据，不带入任何作者历史基准。
