# 图文工作流程

## 1. 确认资料与选题

从用户提供的账号、IP、视觉资料和现有内容判断任务。缺少必要资料时按入口引导补齐，不要求运行配置脚本。用户没有指定题目时，按 `选题规范.md` 推荐适合读者真实场景的选题；有复盘材料就结合数据，没有数据不编造结论。

继续任务时优先使用用户明确指出的内容与已有文件；不猜测多个未完成选题。只有用户要求管理飞书看板时才读取其已授权的看板与选题池。

## 2. 提案并确认选题

给同一选题提供 3-5 个简短标题候选，标出首选，展示核心结论、读者收益、内容主线、点赞/收藏理由、主要内容角色、推荐主模板与理由。用户指定模板优先。确认是否开始创作；通过后锁定标题与主模板，不另加模板确认。

## 3. 写正式内容并查证

在用户工作目录下为本篇建立单独目录，使用 `assets/模板/内容文档模板.md` 编写内容文档。目录名去除不适合文件系统的字符，文档 H1 保留正式标题。

先定知识主线，再决定页数。每页写完整可见文字、知识关系、图解任务与人物预算。按 `内容创作规范.md` 建立事实结论与真实来源映射，检查标题兑现、逻辑、信息增量、动作边界和数字编号。

展示完整逐页方案、视觉方向与发布正文，确认是否开始生成整套图片。未通过事实与内容检查时不请求生图。

## 4. 连续生图与逐页验收

读取本篇内容文档、用户 IP 和视觉资料，查看身份参考图。没有身份参考时先按用户确认的 IP 设定生成主参考图并确认，再用于正式页面。

使用当前可用生图能力生成完整图文卡片。每页提示词包含完整原文、知识关系、统一背景色、人物身份与禁用特征、出现次数和画面预算，并传入需要的参考图。每页生成后立即查看原图，按 `图片生成与验收规范.md` 逐项检查。

失败页重写完整提示词并返工；同一问题每页最多 3 次。用户改变方向、素材缺失、认证/配额错误或持续失败时停止，说明已完成与未完成页。成功一页不等于整套完成，不一张一问。

## 5. 整套检查与直接交付

确认内容文档规定的全部页面都有实际文件，按 `card-1.png` 至末页连续命名，无缺页、重复页或额外旧页。通过可用的文件信息工具核对每张 PNG 为 1080x1440，不靠图片外观猜测尺寸。工具输出其他尺寸时用可用的图像处理能力保持比例转换，再确认文字与图解清晰、无裁断；无法满足时报告限制，不假装验收通过。

归档只保留内容文档与最终生成图片。仅清理本次中间文件，不删除最终图片或历史内容。报告本篇标题、实际页数与成果位置；未通过整套检查不报告完成。

## 6. 按需交付与复盘

默认本地图文交付至此结束。用户明确要求飞书时，按 `飞书交付规范.md` 对其自己的目标记录交付；工具或权限不可用时保留本地成果，说明缺口，不影响本地图文完成。

用户提供数据或要求复盘时，按 `数据反馈与复盘规范.md` 区分周期与累计口径，以真实内容和数据输出结论、证据和下一步动作。账号特有的实验结果留在用户资料中，不直接写入公共规范。
