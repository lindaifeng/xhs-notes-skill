# 数据反馈与复盘规范

## 数据角色

数据用于验证选题、标题、封面、内容兑现和账号关注理由，不代替模型判断。程序可以读取导出文件、清洗字段和计算指标；原因分析、内容判断与策略调整由模型完成。

## 优先采集

单篇尽量记录发布后 24 小时、7 天和 30 天的曝光、观看、封面点击率、点赞、收藏、评论、分享、主页访问和涨粉，并补充栏目、内容角色、标题结构、封面类型、页数和发布时间。缺失字段留空并说明，不编造或用 0 代替。

## 基础口径

- 点赞率、收藏率、评论率、分享率和互动率优先使用观看量为分母。
- 同时存在曝光和平台封面点击率时，封面判断优先使用平台字段。
- 同时报告平均数和中位数；判断典型笔记优先看中位数，判断总贡献使用总量或加权指标。
- 账号周期汇总包含历史笔记当期流量；单篇明细可能是累计值。刷新时间、覆盖范围或口径不一致时分别分析，不强行勾稽。

## 分析顺序

1. 检查日期、字段、空值、重复、异常和口径冲突。
2. 判断总盘趋势与新发笔记稳定性。
3. 对照 `内容文档.md` 中的内容角色、点赞理由、收藏理由和主要风险，判断原始创作假设是否成立、部分成立或尚无足够样本。
4. 分析高阅读、高收藏、高互动和高涨粉笔记的不同机制。
5. 按栏目、内容角色、标题、封面和发布时间比较平均数、中位数及加权指标。
6. 识别高点击低互动、低点击高收藏、高阅读低涨粉等漏斗问题。
7. 使用“结论—证据—动作”输出下一轮调整。

## 因果边界

- 封面、标题或发布时间变化与题材同时发生时，只能标注相关性或假设。
- 比较封面或标题时优先使用相同发布成熟度、相近栏目和相近强度的样本。
- 小样本高比率必须标注观看量，不因单篇爆款或几十次观看直接固化规则。
- 至少完成多组相邻同类测试后，再决定是否更新长期策略。

## 策略沉淀

稳定且不含账号私有信息的方法，经用户同意后可更新通用 Skill；栏目比例、当期基准、具体爆款和短期实验结果保留在使用者自己的复盘记录或私有资料中，不直接写入公共仓库，不硬编码为永久规则。复盘可调整下一轮流量题、收藏题、涨粉题和测试题的组合，但不自动修改用户确认闸门、人物 IP 或长期视觉规范。

## 判断边界

工具用于读取数据与计算指标；选题价值、内容原因、封面效果和优化动作由 Agent 结合数据与真实成品判断，不用自动评分替代内容分析。
