# 小红书图文创作 Skill

供 Agent 读取的图文工作流，覆盖选题、事实查证、写作、人物 IP、视觉设计、生图验收与本地交付。仅支持图文笔记，不包含视频成片流程。

## 开始使用

将此 Skill 交给支持读取 Skill 的 Agent，告诉它：

> 使用 create-xhs-notes，帮助我制作一篇小红书图文笔记。先确认账号定位和我自己的 IP，推荐选题与视觉方案；我确认完整内容后再生成整套图片。

Agent 会先读取入口与工作流程，结合已有资料收集必要信息，不要求先运行安装脚本或填写机器配置。账号/IP/视觉模板用于协助沟通；实际资料保存在使用者自己的工作目录。

生图可使用 Codex 自身能力，或采用其他可用生图模型。使用第三方服务时，使用者自行配置自己的 Key。工具不可用或未授权时先完成配置，不能仅凭加载 Skill 就声称具备生图能力。

## 交付

选题确认后写完整内容，内容与画面方案确认后连续生成、逐页验收。页数根据内容决定；默认交付 `内容文档.md` 与连续 `card-*.png`，图片为 1080x1440 PNG，无需截图。

默认完成本地图文即可。飞书交付与数据复盘按用户需要读取对应规范，不作为首次创作的前置条件。

## 内容范围与隐私

本包仅含工作流规范、资料与内容模板、Agent 展示元数据，以及 MIT 许可证。没有随包脚本、固定安装目录、指定模型、其他 Skill 依赖、真实 Key、人物素材、账号资料或历史运营数据。

用户提供自己的账号定位、IP 与视觉偏好。需要新 IP 时可由 Agent 协助起草并确认；人物参考图、凭证和正式内容均不写进公共模板。在此仓库内试用时将这些文件存入被忽略的 `.local/`，或使用仓库外的工作目录。
